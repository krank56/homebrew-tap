# krank56/tap

Homebrew formulae for [jenklod-batman](https://github.com/krank56/jenklod-batman).

```sh
brew install krank56/tap/jenklod-batman
```

The `bump` workflow checks for a new jenklod-batman release every hour (or when run by hand from the Actions tab). When there is one, it renders the formula with `bin/render-formula`, installs and tests it with brew, and commits it.
